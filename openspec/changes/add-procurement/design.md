# Design: add-procurement

## Decisions
- **Inventory-first 寫進演算法**：P2 是 P3 的前置條件，不能由 LLM 決定是否跳過。
- **商品比對採兩段式**：先以結構化規格欄位（型號、容量、核心數等）硬比對，再由 LLM 判斷剩餘不確定的配對；任一段不一致即視為不同商品。
- **TCO 而非最低價**：排序依價格、保固、運費與交期的加權總持有成本。
- **拆單偵測**：同一請購人或計畫在一定期間內、規格相近、合計金額跨越門檻的請購單，標記為疑似拆單並轉人工。

## Risks
- 網頁結構變動導致擷取失敗 → 擷取失敗計入 NEED_MANUAL_QUOTES，不以 LLM 補值。
- 異常低價可能是規格不符、二手、詐騙或缺貨 → 低於中位數一定比例的報價需標記並說明可能原因。
