## ADDED Requirements

### Requirement: Intent Recognition and Parameter Extraction
The system SHALL classify each user request into one of IMPORT, LEND, VALUE, DISPOSE, PROCURE, or QUERY and SHALL extract the parameters required by that intent.

#### Scenario: Procurement request
- **WHEN** a member submits「幫新進學生準備一台深度學習工作站，預算 12 萬」
- **THEN** the intent is PROCURE
- **AND** the extracted parameters include purpose and budget = 120000

#### Scenario: Inventory question
- **WHEN** a member asks「實驗室現在有哪些可借的 GPU 主機？」
- **THEN** the intent is QUERY and the request is answered from the asset database

### Requirement: Clarification Loop with Turn Limit
The system SHALL ask clarification questions when required parameters are missing and SHALL stop asking after T_max turns (default 3).

#### Scenario: Missing specification
- **WHEN** a PROCURE request has no quantity or specification
- **THEN** the agent asks for the missing fields before searching

#### Scenario: Turn limit reached
- **WHEN** required parameters are still missing after T_max clarification turns
- **THEN** the agent returns a partial result marked NEED_INFO and does not call state-changing tools

### Requirement: Role-Based Authorization
The system SHALL check the user's role before executing an intent; Member MAY query, lend, and request purchases, Custodian MAY import, inventory, and draft disposals, and only PI MAY approve procurement and disposal.

#### Scenario: Unauthorized approval
- **WHEN** a Member attempts to approve a disposal request
- **THEN** the system returns Deny("permission") and records the attempt in the audit log

### Requirement: Deterministic Values Only
The system MUST NOT present a monetary amount, threshold decision, useful-life decision, or disposal decision that was generated by the LLM; every such value SHALL originate from a tool or the rule engine.

#### Scenario: Threshold question
- **WHEN** a user asks whether a 160,000 TWD purchase is a small-value procurement
- **THEN** the answer is produced by the rule engine using rules.yaml
- **AND** the LLM only explains the rule engine's result
